repository — build system, module layout, architecture, and conventions all live there.

This file used to carry its own copy of that guidance. The copy fell behind: it still
described Java 25 as the floor and Paper as a calendar-versioned artifact long after the
build moved to a Java 21 toolchain compiled against the 1.21.4 API, and it still called
blocks, furniture and armor future work after they had shipped. One file cannot be kept
honest by hand while a second one drifts beside it, so this one no longer tries.
