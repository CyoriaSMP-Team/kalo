🚀 Getting Started

Prerequisites

  • Java 21+ (Java 25 for Paper 26.2)
  • Paper or Folia server

Installation

# 1. Build Kalo
git clone https://github.com/CyoriaSMP-Team/kalo.git
cd kalo/main
./gradlew build

# 2. Install plugin
cp build/libs/Kalo-*.jar /path/to/server/plugins/

# 3. Create content pack
mkdir -p plugins/Kalo/packs/myitem/configs
mkdir -p plugins/Kalo/packs/myitem/assets/myitem/textures/item

First Item

# plugins/Kalo/packs/myitem/configs/items.yml
ruby_sword:
  type: item
  display:
    name: "Ruby Sword"
    lore:
      - "A powerful sword"
  model:
    sprite: "item/ruby_sword"
  item:
    material: DIAMOND_SWORD
    durability: 1561
    damage: 7

Commands

CommandDescription
/kalo reloadReload all content packs
/kalo give <player> <item>Give a Kalo item
/kalo migrate <plugin>Migrate from other plugins

🪑 Furniture

Basic Chair

ruby_chair:
  type: furniture
  display:
    name: "Ruby Chair"
  model:
    custom: "furniture/ruby_chair"
  furniture:
    rotatable: true
    restricted_rotation: strict
    seat:
      height: 0.5
      offset: [0.0, 0.5, 0.0]
    hitbox:
      barriers: [[0,0,0]]
  java:
    mode: native

Storage Furniture

ruby_chest:
  type: furniture
  display:
    name: "Ruby Chest"
  model:
    custom: "furniture/ruby_chest"
  furniture:
    storage:
      type: STORAGE
      rows: 5
      title: "Storage"
  java:
    mode: native
