## What is Kalo?

Kalo is a free and open-source engine for building custom items, blocks, furniture, and armor on Paper and Folia servers. One YAML definition compiles to both Java and Bedrock resource packs.

## Quick Start

```bash
# Clone and build
git clone https://github.com/CyoriaSMP-Team/kalo.git
cd kalo/main
./gradlew build

# Install
cp build/libs/Kalo-*.jar /path/to/server/plugins/

# Create content pack
mkdir -p plugins/Kalo/packs/myitem/configs
```
