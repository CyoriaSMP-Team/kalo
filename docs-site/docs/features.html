🔄 Migration (11 plugins)

Kalo can migrate from 11 different plugins.

Supported Plugins

  • Oraxen - Items, blocks, furniture
  • Nexo - Items, blocks, furniture (Oraxen fork)
  • ItemsAdder - Items, blocks, furniture
  • CraftEngine - Items, blocks
  • MMOItems - Items
  • MythicMobs - Mobs, skills
  • ModelEngine - 3D models
  • CrackShot - Guns
  • Neko - Items, blocks

Migration Commands

  • /kalo migrate oraxen - Migrate from Oraxen
  • /kalo migrate itemsadder - Migrate from ItemsAdder
  • /kalo migrate craftengine - Migrate from CraftEngine
  • /kalo migratemmoitems - Migrate from MMOItems
  • /kalo migrate mythicmobs - Migrate from MythicMobs
  • /kalo migrate modelengine - Migrate from ModelEngine
  • /kalo migrate crackshot - Migrate from CrackShot
  • /kalo migrate neko - Migrate from Neko

🌐 Cross-Platform (Geyser)

Kalo has deep Geyser integration for Bedrock support.

Geyser Features

  • Deep API integration - Register blocks/items directly
  • Auto-detect Geyser - Works with Geyser in same JVM
  • Fallback file-based - Works with Geyser in different process
