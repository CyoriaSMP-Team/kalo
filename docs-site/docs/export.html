Export System

Export your Kalo content to various formats with transparent conversion reports.

Import from anywhere. Export anytime. No lock-in.
Kalo doesn't own your content. You do.

Available Exporters

Kalo Pack STABLE

Export your content as a Kalo Pack bundle for backup, sharing, or versioning.

kalo export --format kalo-pack

Use case: Backup your content, share with other servers, or version control.

Canonical JSON STABLE

Export your content as canonical JSON/YAML format for portability.

kalo export --format canonical

Use case: Portable format that can be imported by other tools.

Oraxen EXPERIMENTAL

Export Kalo content to Oraxen format.

kalo export --format oraxen

Note: This is a lossy conversion. Features without Oraxen equivalents will be flagged.

ItemsAdder EXPERIMENTAL

Export Kalo content to ItemsAdder format.

kalo export --format itemsadder

Note: This is a lossy conversion. Features without ItemsAdder equivalents will be flagged.

Nexo EXPERIMENTAL

Export Kalo content to Nexo format.

kalo export --format nexo

Note: This is a lossy conversion. Features without Nexo equivalents will be flagged.

API Usage

Programmatic Export

import io.kalo.export.ExportManager;
import io.kalo.export.ExportReport;
import java.nio.file.Path;

// Create export manager
ExportManager manager = new ExportManager();

// Export to Oraxen format
Path source = Path.of("my-kalo-pack");
Path target = Path.of("exported-oraxen");

ExportReport report = manager.exportToOraxen(source, target);

// Print report
System.out.println(report);

Why Export Matters

No vendor lock-in.
Your content is yours. Export it anytime. Use it anywhere.

Benefits

  • Backup & Recovery: Export your content as a Kalo Pack for safekeeping
  • Migration: Export to other formats if you decide to switch platforms
  • Sharing: Share content with other servers or content creators
  • Version Control: Export to canonical format for Git-friendly workflows
  • Portability: Your content works across platforms and tools
