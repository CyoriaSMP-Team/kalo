Bedrock Support

One YAML definition compiles to a Java pack and to Bedrock output. Kalo writes a .mcpack and registers it with Geyser. Not every Java feature has a Bedrock equivalent, and parts of this are still unverified.

Pre-alpha: only the rows marked tested have been seen on a real Bedrock client. Everything else is covered by unit tests, which cannot prove how it looks in-game.

Setup

Geyser on the same server (recommended)

Install Geyser, optionally Floodgate, then Kalo. Kalo registers items, blocks and the pack with Geyser directly. There is nothing to copy, and regenerating content cannot leave Bedrock on an old copy.

Geyser as a separate process

Kalo cannot detect a separate process, so set bedrock: always. Then either copy the generated files by hand, or let Kalo sync them:

# plugins/Kalo/config.yml
bedrock: always
bedrock-standalone:
  directory: "/path/to/geyser"   # must contain Geyser's config.yml and packs/

Kalo writes only packs/kalo-generated.mcpack and custom_mappings/kalo-*.json. Geyser may need a restart to load changed mappings.

Configuration

KeyDefaultMeaning
bedrockautoauto builds Bedrock output only when Geyser is on this server; always always builds it; never skips it.
bedrock-standalone.directoryemptyExisting standalone Geyser directory to sync into. bedrock: never overrides it.
bedrock-forms.enabledfalseConvert eligible DeluxeMenus menus to Bedrock Forms through Floodgate.

Held 3D items

Bedrock has no display block on models, so Kalo turns the Java model's firstperson_righthand and thirdperson_righthand transforms into per-item hold animations. An item with no display uses the Bedrock Wiki's bound-item pose. The conversion of axis signs and units is an approximation that has not been measured on a client, so an item may sit offset or rotated. Parent models from vanilla (for example item/handheld) are not read, and only the main hand is posed.

DeluxeMenus as Forms

With bedrock-forms.enabled: true and Floodgate installed, Bedrock players get a native form for menus Kalo can convert safely. Menus it cannot convert stay as normal DeluxeMenus inventories. Java players are unaffected. This is experimental.

Existing Java packs

Set base-pack to your Java resource pack, hold a custom item and run /kalo learn-held, then restart so Geyser registers it. Stored observations live in plugins/Kalo/external-items.yml. This is experimental.

Troubleshooting

  • Blocks not rendering: check the Kalo and Geyser logs for registration messages, and restart after the first install.
  • Missing texture on an item: check the texture exists under assets/<pack>/textures/, run /kalo doctor, then /kalo reload.
  • Virtual blocks invisible: this is structural. Use native mode for anything Bedrock players must see.
