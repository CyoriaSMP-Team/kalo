Start in 30 Seconds

Clone, build, and install. That's it.

# 1. Clone the repo
git clone https://github.com/CyoriaSMP-Team/kalo.git
# 2. Build
cd kalo/main && ./gradlew build
# 3. Install
cp build/libs/Kalo-*.jar /your-server/plugins/
# 4. Create your first item
mkdir -p plugins/Kalo/packs/mypack/configs
